BENGALI WEDDING E-CARD — RED THEME CATALOGUE
================================================

Purpose
-------
Keep this file as a backup catalogue of ready-to-use red-family themes.
To switch themes, copy ONE complete `theme: { ... }` block below and replace
the existing `theme` block inside your `config.js`.

Recommended starting points:
- Most traditional: Maroon + Antique Gold
- Most premium: Burgundy Red
- Most festive: Sindoor Red
- Most balanced: Royal Bengali Red
- Most romantic: Wine Red
- Most dramatic: Crimson Red

================================================
QUICK SWITCH GUIDE
================================================

1. Open `config.js`.
2. Find the existing block beginning with:

   theme: {

3. Replace that entire block with one theme from this catalogue.
4. Save `config.js`.
5. Refresh the wedding card in your browser.

Example:

Before:
--------
theme: {
  vermillion: "#8A1F21",
  ...
},

After:
-------
theme: {
  vermillion: "#7A1F2B",
  red: "#9A2D3C",
  deep: "#321015",
  gold: "#C6A15B",
  ...
},

Tip:
----
If you make your own custom theme, copy it into this catalogue as a new
numbered theme before experimenting further. This gives you an easy rollback
point whenever you want to restore an earlier look.
